# Jononippu

Navigoi Organisaation päänäkymään ja valitse pystyvalikon ikonista tai kolmepistevalikosta Jononiput. Uusi jononippu -painike avaa näkymän, jossa pääset nimeämään jononipun. Valitsemalla luomasi jononipun kolmepistevalikkoa pääset hallinnoimaan jononippuun valittuja jonoja, muokkaamaan nimeä tai poistamaan jononipun.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (5).png" alt=""><figcaption><p>Jononipun kolmepistevalikosta pääset hallinnoimaan, muokkaamaan sekä poistamaan jononipun.</p></figcaption></figure></div>

{% hint style="info" %}
Kun haluat poistaa jononipun, tulee sinun ensin poistaa kaikki jonot kyseisestä jononipusta. Tämän jälkeen voit poistaa kyseisen jononipun nimen päänäkymästä.
{% endhint %}
