# Organisaation jäsenten hallinta

## Käyttäjien hallinta organisaatiossa <a href="#kayttajien-hallinta-organisaatiossa" id="kayttajien-hallinta-organisaatiossa"></a>

Organisaatioasetuksiin pääset klikkaamalla organisaation nimeä ja valitsemalla "Organisaation päänäkymä" (Vaatii orgnisaation operaatorin oikeudet). Valitse pistevalikosta kohta "Jäsenet".

Jäsenet -kohdassa näet organisaatioon lisätyt jäsenet (huom. organisaation operaattori on eri asia kuin yksittäisen tiimikanavan operaattori). Tässä näkymässä voit hallinoida jäsenten oikeuksia, jonoja sekä jäsenyyttä.

## Käyttäjän oikeuksien muokkaus

Klikkaa jäsenen rivin oikeassa reunassa olevaa kolmepiste-valikkoa, avataksesi näkymän toiminnallisuuksien hallintaan.

* Lisää/poista hänet käsittelijäksi asiakaspalvelujonoihin.
* Lisää/poista jäsenen organisaation operaattorioikeudet
* Poista jäsen organisaatiosta - toiminta poistaa käyttäjän jonoista ja organisaatiosta. Jäsen tulee erikseen poistaa tiimikanavilta kanavien jäsenlistan kautta.

Katso lisää kohdassa Jäsenen lisääminen jonon käsittelijäksi.
