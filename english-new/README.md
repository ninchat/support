# What’s New?

Welcome to Ninchat´s support site for the redesigned user interface!\
The new interface has been developed in close collaboration with customers and professionals to enhance the user experience and streamline the daily work of professionals.

Users now have more flexibility to manage settings according to their own preferences. At the same time, the visual look and feel of the interface has been refreshed and overall usability has been improved.

Sing in to the new interface from [https://ninchat.com/new](https://ninchat.com/new).
