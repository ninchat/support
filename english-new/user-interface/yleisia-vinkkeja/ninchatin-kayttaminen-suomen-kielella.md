# Ninchat user interface language

Ninchat uses the language selected in your web browser as the default (Finnish/English). You can change the language by navigating to Settings and profile and selecting Language and region.

You can, by choosin the setting Automatic, also change the language through your browser's language settings. You can access the settings directly using the links provided below:

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (116).png" alt=""><figcaption><p>Language and region settings view.</p></figcaption></figure></div>

Voit vaihtaa kielen myös selaimen kieliasetuksista. Asetuksiin pääset suoraan alla kerrotuilla linkeillä:

Chrome\
[chrome://settings/languages](chrome://settings/languages)

Firefox\
about:preferences#general

Edge Chromium\
[edge://settings/languages](edge://settings/languages)

Opera\
[opera://settings/languages](opera://settings/?search=kieli)
