# Having a customer audience

### Start of a conversation <a href="#start-of-a-conversation" id="start-of-a-conversation"></a>

The conversation begins when you pick the customer from the queue. The customer is shown a conversation start message when the chat starts. The message can be edited in the site configuration or by requesting Ninchatt to make the change.

At the top of the conversation field, you can see the conversation metadata, and if there is a pre-audience questionnaire in the chat, you can see the customer’s responses below the metadata. &#x20;

The pre-audience questionnaire start message appears in the conversation, as does the configured screen name.

### Entering a message

Type your message in the command line ("Enter your message"). Send it by clicking \[ENTER] key or the <img src="../../.gitbook/assets/image (99).png" alt="" data-size="line"> Send-icon.

If you need to add line breaks the your messages, you can do by clicking simultaneously \[SHIFT]+\[ENTER] keys. The command line will automatically adjust to longer messages.

### Pictures and files <a href="#pictures-and-files" id="pictures-and-files"></a>

The agent can send pictures and files to the customer, and vice versa if allowed in the queue settings.

By clicking the attachment icon (<img src="../../.gitbook/assets/image (89).png" alt="" data-size="line">), you can select the file to attach. The selected file can still be removed before you press "Send." After this, the attachment will appear in the customer's view.

There is no limit to the size or format of files to upload.

### Customer metadata <a href="#customer-metadata" id="customer-metadata"></a>

Various metadata can be passed from the customer to expedite and facilitate the work of the agent. The data which may be communicated are:

* From the web page at the beginning of the chat and in real time during the chat
* Ninchat pre and post questionnaire responses
* Collected metadata such as the contents of the shopping cart

### Use of the canned message

You can find predefined responses by clicking the icon located below the text field. You can select a message by clicking it, and it will appear in the text field. If necessary, you can edit the text or send it immediately.

You can find predefined responses by clicking the icon located below the text field <img src="../../.gitbook/assets/valmisvastaukse.png" alt="" data-size="line">. You can select a message by clicking it, and it will appear in the text field. If necessary, you can edit the text before sending the message.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (122).png" alt=""><figcaption><p>Canned messages icon in the bottom bar of the text field.</p></figcaption></figure></div>

#### Access canned messages by using the keyboard

Canned messages can also be accessed by using your keyboard to type in the text field. Canned messages also work from the keyboard in team channels and private conversations.

By typing the slash \[/] and the keyword of a canned message you want to use and pressing the \[Spacebar] key, the canned message will appear in the text field.

Example: You have set up a canned message: open (keyword): We are open on weekdays from 9 am to 5 pm (canned message).

<table><thead><tr><th width="191.3046875">Keyword</th><th>Canned message</th></tr></thead><tbody><tr><td>open</td><td>We are open on weekdays from 9 am to 5 pm.</td></tr></tbody></table>

```
/open[Spacebar] --> We are open on weekdays from 9 am to 5 pm.
```

### Organization shared canned messages

In the organization settings, under the Organization shared canned messages section, you can set predefined responses that apply organization-wide per queue.&#x20;

To create an organization-wide predefined response, click the "Add New" button and enter a keyword for finding the response, along with the message itself. Don’t forget to save. The predefined response will now be available to all organization members.

## Tags <a href="#tags" id="tags"></a>

Customer service agents can tag customer conversations with tags according to the topic or nature of the conversations, for example, "sales", "customership", "technical problem", etc. Adding tags makes it easier to record and later review the conversations.

Conversations can also be tagged automatically e.g. based on questionnaire answers. So it is possible the conversation has added tags right in the beginning.

Used tags are defined by your organization operator.

### Tag a conversation <a href="#tag-a-conversation" id="tag-a-conversation"></a>

An agent can add a tag by choosing from the list of tags in the chat features. Added tags appear and are stored in the metadata in the beginning of the conversation.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (125).png" alt=""><figcaption><p>The tags can be found in the header of the text area.</p></figcaption></figure></div>

### Notes <a href="#notes" id="notes"></a>

Notes is an advanced option that allows you to create notes and entries about a customer conversation. Notes made by a customer service representative are stored in the conversation history. Notes can also be used to export data to the customer's own information system.

Notes can be added via the Notes tab above the message field (if notes are enabled). Remember to click Save. Saved notes are added to the metadata at the beginning of the conversation.

## Real-Time monitoring of conversation

You can review conversation history from the Queue activity view as follows: first, select the queue and click on the name to open the activity view. In this view, you will see all the conversations in the queue. After the member's name, there is a document icon <img src="../../.gitbook/assets/image (130).png" alt="" data-size="line">, which you can click to open the conversation. Note that operator rights are required for this action.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (131).png" alt=""><figcaption><p>Open a specific conversation from the incon on the right in the queue activity view.</p></figcaption></figure></div>

During a customer conversation, you can view all the content of the specific audience, as well as see the conversation in real-time. The customer conversation updates when you click the Refresh button.
