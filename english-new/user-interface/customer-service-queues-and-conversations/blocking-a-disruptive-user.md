# Blocking a disruptive user

Occasionally, inappropriate behavior may occur in the chat. You can block a disruptive user, preventing participation in the conversation from that specific address entirely. Click the three-dot menu at the top of the chat window. In the menu that opens, select "Block IP Address." The block will remain active for 48 hours.

1. Click the three-dot menu at the top of the chat window
2. In the menu that opens, select "Block IP Address
