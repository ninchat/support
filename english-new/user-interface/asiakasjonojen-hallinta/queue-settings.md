# Queue settings

Go to the customer queue settings by clicking the arrow icon next to the queue name. Select "Queue settings.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (136).png" alt=""><figcaption><p>Choose Queue settings from the dropdown menu.</p></figcaption></figure></div>

### **Name and organization**

In the "Name and organization" section, you can set and modify the queue name.

### **Video Conversation**

In the "Video Conversation" section, you can decide who initiates the conversation and how it starts. If the video conversation is set to begin at the expert's initiative, only the expert can start the video conversation. Text-based conversation is also possible, allowing the video to be opened if needed. You can select a video meeting option when you want to allow either party to initiate the video conversation.

### **Who Can Upload Files to the Conversation**

Here, you can choose whether to restrict file sharing, for example, to professionals only, or allow the customer to share files in the conversation as well. You can also disable file sharing entirely, so no one is able to upload files.

### **Metadata**

In the metadata settings, you can choose what information about the conversation is transmitted and who can view it.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (137).png" alt="" width="375"><figcaption><p>The queue settings view.</p></figcaption></figure></div>

**In the queue general settings, you can edit the following:**

* Change the queue name.
* Chose text or video chat.
* Chose who can upload files during the conversation.
* Set whether metadata, such as the customer's location and IP address, is automatically attached at the beginning of the conversation. For additional information about adding other metadata, please contact Ninchat staff.
* Define encrypted metadata as mandatory (see more details in: Customer Queues and Conversations).

{% hint style="info" %}
Remember to save the changes you make
{% endhint %}

## Advanced settings

In advanced settings, you can set up transfer queues, manage audience registering and ticketing, and ad notes in the editor.

### Transfer queue

You can select the queues to which you want to transfer the customer. Choose the desired queues from the list that opens under the 'Set transfer queues' section. You can also search for a specific queue by typing the beginning of its name in this section. Click the Add button next to the desired queue, and it will be added to the selected queues.

Queue settings define the allowed transfer queues. For further details, please contact Ninchat personnel.

### Audience registering

Save offline contacts or questionnaire answers and selections e.g. for statistics

### Audience ticketing

Registered contacts can be assigned as tickets. Unassigned contacts are displayed as highlighted.

### Notes

Notes is an advanced feature which allows adding one or more form fields within a customer care conversation that can be saved as notes. Notes made by customer service representatives are also stored in chat history.

Contact Ninchat staff for more information.
