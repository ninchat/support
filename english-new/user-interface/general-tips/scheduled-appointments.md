# Scheduled appointments

Scheduled appointments are shown in a separate view for users who have been invited to the appointment.

## Open scheduled appointments

1. Open the user menu in the sidebar.
2. Select **Scheduled appointments**.

Appointments are grouped by date. The view shows today’s and tomorrow’s appointments, as well as past appointments. Use the pagination controls to view more appointments.

Each appointment card shows the appointment time, channel, queue, organization, and participants. Select the arrow on the right side of the card to open more details, including the description and participant information.

## Join an appointment

Select **Join now** before the appointment begins. When the appointment is in progress, select **Ongoing – join**.

The appointment opens in its channel. If the appointment has already ended, it is still available in the list as a past appointment, but it can no longer be joined as an ongoing appointment.
