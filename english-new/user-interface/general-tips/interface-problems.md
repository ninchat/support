# Interface problems

#### **The full channel member list is not visible**

Some channel members are shown in Ninchat's top bar. When a person is present, the status indicators show their state (green = present, orange = in another view, and no indicator = not signed in). To see the names of channel members, click the <img src="https://lh4.googleusercontent.com/Hk-PH7HMw4Eem1ckfyEYjyVRYYGR6LWrPtjStpRtFbTIEK52G5mNJ_cA4hxpUYo_dmPFRhWTWZVjpCJDtcRCc_Zsz9yGuubCKUlJ_CEiyMdacYUeBmVMUDHc6XoocnGfo5e7QxHLxu2He9WpwN2ZmZ8" alt="" data-size="line"> button shown after the people. The channel information bar covers some other functions, so remember to close it when you want to write a message, for example.
