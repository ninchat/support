# Queue groups

This feature eliminates the need for professionals to choose which queue to pick up a customer from. Navigate to Organization overview and select "Queue groups" from the vertical menu or the three-dot menu. The New queue group button opens a view where you can name the queue bundle. By opening the three-dot menu for the queue group you created, you can manage the queues included in the group, edit its name, or delete the queue group.

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (166).png" alt=""><figcaption><p>From the queue group’s three-dot menu, you can manage, edit, or delete the queue groups.</p></figcaption></figure></div>

{% hint style="info" %}
To delete a queue bundle, you must first remove all queues from the bundle. After that, you can delete the queue bundle by removing its name from the main view.
{% endhint %}
