# Tags

### General

Tags provide members with an easy and quick way to categorize customer conversations. They help with conversation statistics by enabling completed conversations to be categorized. You can view the tags used in the queue statistics.

Organization operators can add, edit, and delete tags.

## Editing tags

<div data-with-frame="true"><figure><img src="../../.gitbook/assets/image (167).png" alt=""><figcaption></figcaption></figure></div>

1. Click the tag name to edit or delete it.
2. Click the paint icon to change the tag’s color. Colors are a useful way to distinguish tags belonging to different categories.
3. Add a subtag to the category.
4. Add a top-level tag (category).
