# Creating a new channel

To create a new channel, you must have operator rights. Start by navigating to your organization. Then click on the "Channels" section and in the opened view, select the "New channel" button.

1. Select your organization from the left-hand sidebar.
2. Click on the "Channels" section.
3. Click the "New channel" button.

<figure><img src="../../.gitbook/assets/image (152).png" alt=""><figcaption></figcaption></figure>

In the opened window, provide a descriptive name and topic for the channel that reflects what will be discussed there. You can also add links that you wish to display in the channel's description text.

In the "Channel clolsed info" section, you can write information and instructions for situations when the channel is closed. A channel can be closed via the "Channel settings" section.

All the settings for the channel can be edited later.
